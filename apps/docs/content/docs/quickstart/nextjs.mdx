Next.js is a full-stack [React](https://react.dev/) framework. Serverless hosts such as [Vercel](https://vercel.com/) do not hold WebSocket connections. Run the realtime server with the [Node.js](/docs/quickstart/nodejs) or [Cloudflare Workers](/docs/quickstart/cloudflare-workers) quickstart, and use the Next.js app for authorization and the React client.

## Installation

| Purpose                                                 | Location | Install command            |
|---------------------------------------------------------|----------|----------------------------|
| Call and listen to events. Interact with shared storage | Client   | npm install @pluv/client   |
| React bindings for @pluv/client                         | Client   | npm install @pluv/react    |
| Shared user, presence, and storage contract             | Both     | npm install @pluv/treaty   |

```bash
npm install @pluv/client @pluv/react @pluv/treaty
npm install react react-dom @types/react @types/react-dom zod
```

Install `@pluv/io` and a platform package on the server, not in the Next.js client bundle. See the Node.js or Cloudflare quickstart for that setup.

## Authorization route

The server's `ioServer.createToken` mints the room JWT. This route is an example of calling it from a Next.js route handler. Point it at the same `ioServer` the WebSocket server uses.

```ts
// app/api/pluv/authorize/route.ts

import { ioServer } from "@/server/pluv";
import { getSession } from "@/server/auth";

export const GET = async (request: Request) => {
  const url = new URL(request.url);
  const { session } = await getSession(request);

  if (!session) {
    return new Response(JSON.stringify({ error: "Unauthorized" }), { status: 401 });
  }

  const room = url.searchParams.get("room");
  if (!room) {
    return new Response(JSON.stringify({ error: "Missing room" }), { status: 400 });
  }

  const token = await ioServer.createToken({
    room,
    user: {
      id: session.user.id,
      name: session.user.name,
    },
  });

  return new Response(token, { status: 200 });
};
```

See [Authorization](/docs/guides/authorization) for the token contract.

## Client bundle

`wsEndpoint` is the WebSocket server from the Node.js or Cloudflare quickstart.

```ts
// frontend/pluv.ts

"use client";

import { createClient } from "@pluv/client";
import { createBundle } from "@pluv/react";
import type { ioServer } from "@/server/pluv";
import { treaty } from "@/shared/treaty";

export const client = createClient<typeof ioServer>().config({
  treaty,
  authEndpoint: ({ room }) => `/api/pluv/authorize?room=${room}`,
  wsEndpoint: ({ room }) => {
    const host = process.env.NEXT_PUBLIC_PLUV_HOST ?? document.location.host;
    const protocol = document.location.protocol.includes("https") ? "wss:" : "ws:";

    return `${protocol}//${host}/api/pluv/room/${room}`;
  },
});

export const {
  PluvRoomProvider,
  usePresence,
  useStorage,
  useMyself,
  useOthers,
  useTransact,
} = createBundle(client);
```

## Room provider

```tsx
// app/[room]/layout.tsx

import type { FC, ReactNode } from "react";
import { PluvRoomProvider } from "@/frontend/pluv";

interface PageProps {
  children?: ReactNode;
  params: Promise<{ room: string }>;
}

const Page: FC<PageProps> = async (props) => {
  const { children, params } = props;
  const { room } = await params;

  return <PluvRoomProvider room={room}>{children}</PluvRoomProvider>;
};

export default Page;
```

Hooks from `createBundle` work in client components under this layout.
