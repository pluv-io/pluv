`@pluv/io` is designed to be self-hosted on the [Node.js](https://nodejs.org/) runtime. Let's step through how we'd put together a real-time API for Node.js.

## Installation

To install pluv.io for Node.js (self-hosted), we will install the following packages from pluv.io:

| Purpose                                                 | Location | Package                  |
|---------------------------------------------------------|----------|--------------------------|
| Register websockets and custom events                   | Server   | `@pluv/io`               |
| Call and listen to events. Interact with shared storage | Client   | `@pluv/client`           |
| React-bindings for @pluv/client                         | Client   | `@pluv/react`            |
| Adapter for Node.js runtime                             | Server   | `@pluv/platform-node`    |
| Shared user, presence, and storage contract             | Both     | `@pluv/treaty`           |
| yjs CRDT                                                | Both     | `@pluv/crdt-yjs`         |

### Installation Example

Copy the install command for your package manager:

```npm
# Shared contract
npm install @pluv/treaty

# For the server
npm install @pluv/io @pluv/platform-node
# Server peer dependencies
npm install ws zod

# Optional if you wish to use CRDT storage
# For storage capabilities
npm install @pluv/crdt-yjs
# Storage peer dependencies
npm install yjs
```

### Create PluvIO instance

Define an io (websocket client) instance on the server codebase:

```ts
// server/io.ts

import { createIO } from "@pluv/io";
import { platformNode } from "@pluv/platform-node";
import { Database } from "./db";
import { treaty } from "../shared/treaty";

export const io = createIO()
  .platform(platformNode())
  .config({
    treaty,
    secret: process.env.PLUV_AUTH_SECRET!,
    context: () => ({
      db: new Database(process.env.DATABASE_URL),
    }),
    debug: process.env.NODE_ENV === "development",
  });

export const ioServer = io.server({
  // Only if you're using storage (`treaty.storage`)
  getInitialStorage: async ({ room, context }) => {
    const { db } = context;

    // Stubbed example DB query
    const rows = await db.sql(
      "SELECT storage FROM room WHERE name = ?;",
      [room]
    );
    const storage = rows[0]?.storage;

    return storage;
  },
  // Optional: Triggered when a room is destroyed. Use for cleanup if needed.
  onRoomDestroyed: async ({ room }) => {
    // Room destroyed - use for cleanup if needed
  },
  // Optional: Only if you want to run code when storage is destroyed,
  // such as saving the last storage state. Only fires when storage was
  // initialized via initializeSession
  onStorageDestroyed: async ({ room, encodedState, context }) => {
    // Upsert the db room with last storage state
  },
});
```

### Integrate PluvIO with ws

Integrate with [ws](https://www.npmjs.com/package/ws) on your Node.js server.

```ts
// backend/server.ts

import { createServer } from "node:http";
import { manageSessions, type RoomSessionManager } from "@pluv/io";
import Ws from "ws";
import { ioServer } from "./io";

const rooms = new Map<string, RoomSessionManager>();

const getSessions = (roomId: string): RoomSessionManager => {
  const existing = rooms.get(roomId);
  if (existing) return existing;

  const room = ioServer.createRoom(roomId);
  const sessions = manageSessions(room);

  rooms.set(roomId, sessions);

  return sessions;
};

const server = createServer(async (req, res) => {
  const url = new URL(req.url ?? "/", "http://localhost");

  if (req.method !== "GET" || url.pathname !== "/api/pluv/auth") {
    res.writeHead(404).end();
    return;
  }

  const room = url.searchParams.get("room");
  if (!room) {
    res.writeHead(400).end("Missing room");
    return;
  }

  const user = await getUser(req);
  const token = await ioServer.createToken({ request: req, room, user });

  res.writeHead(200, { "content-type": "text/plain" }).end(token);
});

const wsServer = new Ws.WebSocketServer({ server });

// Attach message, close, and error before register. ws drops frames
// that arrive with no listener, and register waits on authorization.
wsServer.on("connection", async (ws, req) => {
  const url = new URL(req.url ?? "/", "http://localhost");
  const roomId = url.searchParams.get("room");
  if (!roomId) {
    ws.close();
    return;
  }

  const sessions = getSessions(roomId);
  const token = url.searchParams.get("token");

  ws.on("message", async (data) => {
    await sessions.onMessage(ws)({ data });
  });
  ws.on("close", async (code, reason) => {
    await sessions.onClose(ws)({ code, reason: reason.toString() });
  });
  ws.on("error", async (error) => {
    await sessions.onError(ws)({ error, message: error.message });
  });

  await sessions.register(ws, { request: req, token });
});

server.listen(3000);
```

### Create the client bundle

```ts
// frontend/pluv.ts

"use client";

import { createClient } from "@pluv/client";
import { yjs } from "@pluv/crdt-yjs";
import { createBundle } from "@pluv/react";

// Use a type-import, since this will be used on the frontend
import type { ioServer } from "./server/pluv";

export const client = createClient<typeof ioServer>().config({
  // Wherever your auth endpoint was
  authEndpoint: ({ room }) => `/api/pluv/auth?room=${room}`,
  wsEndpoint: ({ room }) => {
    const host = document.location.host;
    const protocol = document.location.protocol;
    const wsProtocol = protocol.includes("https") ? "wss:" : "ws:";

    // Or wherever you intend to receive the connection requests from
    return `${wsProtocol}//${host}/api/pluv/room?room=${room}`;
  },
});

// Destructure the bundle, as the app router will not allow accessing
// properties of objects within server components (e.g. you are unable to
// write pluv.PluvRoomProvider in a layout that is a server component)
export const {
  PluvRoomProvider,

  usePresence,
  useStorage,
  useStorageField,
  useMyself,
  useOthers,
  useRoom,
  useTransact,

  // ... Other values as needed

  // Alternatively for things that will only be used in client components
  // (i.e. not server components)
  ...pluv,
} = createBundle(client);
```

### Wrap the PluvRoomProvider

At the route the room's layout will be defined, wrap the page with the `PluvRoomProvider` that was destructured from the previous step. This is necessary to enable all other functions from `createBundle`.

```tsx
import type { FC, ReactNode } from "react";

interface PageProps {
  children?: ReactNode;
  params: Promise<{ room: string }>;
}

const Page: FC<PageProps> = async (props) => {
  const { room } = await params;

  return (
    <PluvRoomProvider room={room}>
      {children}
    </PluvRoomProvider>
  );
};

export default Page;
```

And that's it! With this, functions (e.g. hooks) from `createBundle` can be used for components within your provider.
