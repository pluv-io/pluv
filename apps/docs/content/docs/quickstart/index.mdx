Pick a platform to get started:

- [Next.js](/docs/quickstart/nextjs): React client, with the WebSocket server on Node.js or Cloudflare
- [Cloudflare Workers](/docs/quickstart/cloudflare-workers): self-hosted on Workers
- [Node.js](/docs/quickstart/nodejs): self-hosted on Node.js
