---
title: "Server Events"
description: "Define type-safe custom events on your PluvIO backend with validated procedures and automatic typing."
---

Define custom events on your backend `PluvIO` instance. The client types follow the server procedures.

## Usage example

```ts
import { createIO } from "@pluv/io";
import { platformNode } from "@pluv/platform-node";
import { z } from "zod";

const io = createIO()
  .platform(platformNode())
  .config({
    treaty,
    secret: process.env.PLUV_AUTH_SECRET!,
  });

// Create your custom events as procedures
const sendMessage = io.procedure
  .input(z.object({ message: z.string() }))
  .broadcast(({ message }) => ({
    receiveMessage: { message },
  }));

const doubleValue = io.procedure
  .input(z.object({ value: z.number() }))
  .broadcast(({ value }) => ({
    receiveValue: { value: value * 2 },
  }));

const wave = io.procedure
  .broadcast(() => ({
    receiveMessage: { message: "Hello world!" },
  }));

// Then add the procedures to your router
const router = io.router({
  sendMessage,
  doubleValue,
  wave,
});

// Lastly, add the router to your server, so that it can begin accepting
// custom events
const server = io.server({ router });
```
