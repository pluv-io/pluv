---
title: "Custom Events"
description: "Define type-safe custom events on the server and broadcast them from connected clients."
---

Custom events are defined on the server with `io.procedure` and registered with `io.router`. A client calls `room.broadcast` with that event name. The server procedure validates the input and decides what connected peers receive.

```
┌──────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│ User broadcasts  ├───►│ Server procedure ├───►│ Broadcast to    │
│ an event         │    │                  │    │ connected peers │
└──────────────────┘    └──────────────────┘    └─────────────────┘
```

If a message has no server procedure, it is forwarded as sent. Define the procedure when the event should be validated or rewritten.

See [Server events](/docs/guides/events/server) for the procedure API. Clients subscribe with `room.subscribe.event` or `useEvent`.
