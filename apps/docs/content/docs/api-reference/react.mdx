## createBundle

Returns a `CreateBundle` instance

Creates a bundle to be able to access the `PluvClient` and `PluvRoom` from various react hooks.

```ts
import { createClient } from "@pluv/client";
import { createBundle } from "@pluv/react";
import type { ioServer } from "./server/pluv";
import { treaty } from "./shared/treaty";

const client = createClient<typeof ioServer>().config({
  treaty,
});

export const {
  // components
  MockedRoomProvider,
  PluvProvider,
  PluvRoomProvider,

  // utils
  event,

  // hooks
  useBroadcast,
  useCanRedo,
  useCanUndo,
  useClient,
  useConnection,
  useDoc,
  useEvent,
  useMyPresence,
  useMyself,
  useOther,
  useOthers,
  usePresence,
  useRedo,
  useRoom,
  useRoomError,
  useRoomStats,
  useStorage,
  useStorageField,
  useTransact,
  useUndo,
} = createBundle(client);
```

### suspense

By default, storage hooks return `null` until CRDT storage is loaded. Pass `{ suspense: true }` to make them wait instead.

Wrap the components that use those hooks in `<Suspense>`. This applies to `useStorage`, `useStorageField`, `useDoc`, `useTransact`, and the undo/redo hooks. Presence and connection hooks do not wait. If the room closes or storage becomes unavailable while a hook is waiting, the nearest error boundary handles the rejection.

```ts
const { useStorageField } = createBundle(client, { suspense: true });
```

## CreateBundle

This is the bundle returned from `createBundle`.

### MockedRoomProvider

React provider component to mock `PluvRoomProvider`. Enables hooks from `CreateBundle` while completely offline. This can be useful in [Storybook](https://storybook.js.org/) within a storybook decorator when mocking `PluvRoomProvider`.

```tsx
import { MockedRoomProvider } from "./io";

const MyComponent: FC = () => {
  return (
    <MockedRoomProvider
      // Stand in for the server router. Broadcasting sendMessage
      // delivers receiveMessage to useEvent and subscribe.
      events={{
        sendMessage: ({ message }) => ({
          receiveMessage: { message },
        }),
      }}
      // Define your initial presence
      initialPresence={{
        selectionId: null,
      }}
      // Define the initial storage for the room
      initialStorage={{
        messages: [],
      }}
      // The room's id
      room="my-mock-room"
    >
      {children}
    </MockedRoomProvider>
  );
};
```

### PluvProvider

React provider component to allow the `PluvClient` created by `createClient` to be accessible in child components via `useClient`. This is identical to importing the created client, so this is primarily useful for dependency injection when testing.

```tsx
<PluvProvider>{children}</PluvProvider>
```

### PluvRoomProvider

React provider component to enable `CreateBundle` hooks within child components. Mounting this component connects to a real-time room with other connected users. Unmounting this component will disconnect the room. See [Create Rooms](/docs/guides/rooms/react) for more details.

```tsx
import { yjs } from "@pluv/crdt-yjs";
import { MockedRoomProvider } from "./io";

const MyComponent: FC = () => {
  return (
    <PluvRoomProvider
      // Optional: Set the value of `connect` to trigger a connect or
      // disconnect of the room.
      // Default: true
      connect={true}
      // Required when the treaty defines presence: the user's
      // initial presence value
      initialPresence={{
        selectionId: null,
      }}
      // Optional: Overwrite the initialStorage value from the client
      initialStorage={{
        messages: [],
      }}
      // Optional: Called when the room token is rejected
      onAuthorizationFail={(error: Error) => {
        console.error(error);
      }}
      // Required: The room's id
      room="my-room-id"
    >
      {children}
    </PluvRoomProvider>
  );
};
```

### event

typeof `EventProxy`

`event.receiveMessage.useEvent(callback)` is [`useEvent`](/docs/api-reference/react#useevent)`("receiveMessage", callback)`. [`useBroadcast`](/docs/api-reference/react#usebroadcast) sends the event.

```tsx
// The below 2 statements are equivalent
useEvent("receiveMessage", ({ data }) => {
  console.log(data.message);
});

event.receiveMessage.useEvent(({ data }) => {
  console.log(data.message);
});
```

### useBroadcast

Returns `BroadcastProxy`

Sends an event defined on the server router. `broadcast(name, input)` and `broadcast.name(input)` are the same call. [`useEvent`](/docs/api-reference/react#useevent) receives one. On the client, [`room.broadcast`](/docs/api-reference/client#pluvroombroadcast). See [Define Events](/docs/guides/events/server).

```tsx
const broadcast = useBroadcast();

// The below 2 statements are equivalent
broadcast("sendMessage", { message:  "Hello world~!" });

broadcast.sendMessage({ message: "Hello world~!" });
```

### useCanRedo

Returns `boolean`

Checks whether calling [PluvRoom.redo](/docs/api-reference/react#useredo) will mutate storage.

```ts
const canRedo: boolean = useCanRedo();
```

### useCanUndo

Returns `boolean`

Checks whether calling [PluvRoom.undo](/docs/api-reference/react#useundo) will mutate storage.

```ts
const canUndo: boolean = useCanUndo();
```

### useClient

Returns `PluvClient`

Returns the `PluvClient` that was created via `createClient`.

### useConnection

Returns `WebSocketConnection`

Returns the websocket connection start of the current user.

```tsx
const connection = useConnection();
//    ^? const connection: {
//        id: string | null;
//        state: ConnectionState;
//    }
```

### useDoc

Returns `AbstractCrdtDoc`

This returns an instance of the `AbstractCrdtDoc` that holds the underlying CRDT doc. For instance, when using `@pluv/crdt-yjs`, this will hold a [yjs](https://yjs.dev/) doc in its `value` property.

```ts
import { yjs } from "@pluv/crdt-yjs";
import { Doc as YDoc } from "yjs";

const doc: yjs.CrdtYjsDoc<any> = useDoc();
const ydoc: YDoc = doc.value;
```

### useEvent

Returns `void`

Receives an event. `useEvent(name, callback)` and [`event`](/docs/api-reference/react#event)`.name.useEvent(callback)` are the same listener. [`useBroadcast`](/docs/api-reference/react#usebroadcast) sends one. On the client, [`room.subscribe.event`](/docs/api-reference/client#pluvroomsubscribeevent).

```tsx
useEvent("messageReceived", ({ message }) => {
  console.log(message);
});
```

### useRoom

Returns the `PluvRoom` for the surrounding `PluvRoomProvider`.

Throws if the component is not under a `PluvRoomProvider`. The other hooks in this bundle call this internally.

```tsx
const room = useRoom();

room.broadcast.sendMessage({ message: "hello" });
```

### useRoomError

Returns `void`

A room failure: a procedure throw, a size limit, or a rejected register. Same errors as [`room.subscribe.error`](/docs/api-reference/client#pluvroomsubscribeerror). The WebSocket `error` event is [`room.addEventListener("error")`](/docs/api-reference/client#pluvroomaddeventlistener).

```tsx
useRoomError((error) => {
  console.error(error.message);
});
```

### useMyPresence

Returns `[myPresence: TPresence | null, updatePresence: Function]`

The current presence value and [`updateMyPresence`](/docs/api-reference/client#pluvroomupdatemypresence). Call this to read or patch fields. [`usePresence`](/docs/api-reference/react#usepresence) runs a treaty presence procedure. A selector narrows the value and skips rerenders when that result is unchanged.

```tsx
// Presence shape comes from the shared treaty, not from client config.
const { useMyPresence } = createBundle(client);

const [
  // the user's presence
  myPresence,
  // a presence updater function
  updateMyPresence
] = useMyPresence();

// update individual base properties
updateMyPresence({ selectionId: "name-input" });
updateMyPresence({ selectionColor: "#123456" });

// update multiple base properties
updateMyPresence({
  selectionId: "name-input",
  selectionColor: "#123456",
});

// if you only need a partial presence
const [myPresence] = useMyPresence(({ selectionId }) => selectionId);

// if you don't need presence, and just want the updater
const [, updateMyPresence] = useMyPresence(
  // set selector to return a stable value
  () => true
);
```

### useMyself

Returns `UserInfo | null`

Returns the user-info object for the current user. This hook accepts a selector to return a modified user-info to reduce rerenders.

```tsx
const myself = useMyself();

const userId = useMyself(({ data }) => data.id);
```

### useOther

Returns `UserInfo | null`

Returns one other person by `data.id`. Omit `kind` for the user. Pass `{ kind: "operator" }` for the operator. An id-only lookup does not return someone who is only an operator.

```tsx
const other = useOther(userId);

const selectionId = useOther(userId, (other) => other.presence.selectionId);
const operator = useOther(userId, (other) => other, { kind: "operator" });
```

### useOthers

Returns `readonly UserInfo[]`

`useOthers(selector?, { kinds?, isEqual? })`. `kinds` is `readonly ("user" | "operator")[]` and is the second argument, after the selector. Omit it for users. `"operator"` is operators. Both values together include both. Same bag as [`room.getOthers`](/docs/api-reference/client#pluvroomgetothers). Presence updates rerender this list.

> **Note**
> Consider using this hook only for deriving others' `data.id` values to pass into `useOther`.

```tsx
const others = useOthers();

const userIds = useOthers((others) => {
  return others.map(({ data }) => data.id);
});

const operators = useOthers((others) => others, { kinds: ["operator"] });
```

### useRedo

Returns `void`

Re-applies the last mutation that was undone via [PluvRoom.undo](/docs/api-reference/react#useundo).

For more information see: [History](/docs/guides/history)

```ts
const redo = useRedo();

redo();
```

### useRoomStats

Returns `RoomStats`

`useRoomStats(selector?, { kinds?, isEqual? })`. `connectionCount` and `userCount`. `kinds` is `readonly ("user" | "operator")[]` on the second argument and scopes both fields. Omit it for users. Same bag as [`room.getRoomStats`](/docs/api-reference/client#pluvroomgetroomstats).

```ts
const { connectionCount, userCount } = useRoomStats();
const viewers = useRoomStats((stats) => stats.userCount);
const operators = useRoomStats((stats) => stats.userCount, { kinds: ["operator"] });
```

### usePresence

The treaty presence procedure proxy ([`room.presence`](/docs/api-reference/client#pluvroompresence)). Call this to run a procedure. [`useMyPresence`](/docs/api-reference/react#usemypresence) reads and patches the current value. Do not destructure the proxy.

```ts
const presence = usePresence();

presence.select({ id: "item-1" });
```

### useStorage

The treaty storage procedure proxy ([`room.storage`](/docs/api-reference/client#pluvroomstorage)). Call this to run a procedure. Procedures throw until storage is loaded. [`useStorageField`](/docs/api-reference/react#usestoragefield) reads one field. Do not destructure the proxy.

```ts
const storage = useStorage();

storage.addMessage({ text: "hello" });
```

### useStorageField

Returns `[TData | null, SharedType | null]`

`useStorageField(key)` returns `[json, sharedType]` for one top-level field. Call this to read a field. Both values are `null` until storage is loaded. With `createBundle(client, { suspense: true })`, the hook waits and both are defined. [`useStorage`](/docs/api-reference/react#usestorage) runs a procedure. [`room.getStorage`](/docs/api-reference/client#pluvroomgetstorage) is the native type. [`room.getStorageJson`](/docs/api-reference/client#pluvroomgetstoragejson) is the snapshot.

```tsx
const [messages, sharedType] = useStorageField("messages");

sharedType?.push(["world~!"]);

messages?.map((message, key) => <div key={key}>{message}</div>);
```

### useTransact

Returns `void`

Performs a mutation that can be tracked as an operation to be undone/redone (undo/redo). When called without an origin, the origin will default to the user's connection id.

You can specify a 2nd parameter to transact with a different transaction origin.

For more information see: [History](/docs/guides/history)

```ts
const [messages, sharedType] = useStorageField("messages");
const transact = useTransact();

transact((tx) => {
  sharedType.push(["hello world!"]);

  // Alternatively, access your storage from here
  tx.messages.push(["hello world!"]);
});

// This will also be undoable if `"user-123"` is a tracked origin.
transact(() => {
  sharedType.push(["hello world!"]);
}, "user-123");
```

### useUndo

Returns `void`

Undoes the last mutation that was applied via [PluvRoom.transact](/docs/api-reference/react#usetransact).

For more information see: [History](/docs/guides/history)


```ts
const undo = useUndo();

undo();
```
