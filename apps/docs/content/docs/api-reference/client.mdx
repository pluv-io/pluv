## createClient

`createClient<typeof ioServer>().config(options)` returns a `PluvClient`.

Pass `options` to `.config()`. The type argument is your server. See [Create Client](/docs/guides/create-client).

`options`:

- `treaty` — the shared treaty
- `authEndpoint` — where the client fetches a room token. `true` fetches `GET /api/pluv/authorize?room=`. A string is fetched as a URL. `({ room, metadata }) => string` returns the URL. `({ room, metadata }) => { url, options }` also passes `fetch` init (`RequestInit`), for a `POST` body or extra headers
- `wsEndpoint` — a string, or `({ room, metadata }) => string`. Omitted, the client connects to `/api/pluv/room/${room}`
- `initialStorage` — JSON seed. Allowed when the treaty defines storage. `createRoom` can override it
- `metadata` — a schema for values passed to `enter` and the endpoint functions
- `debug` — `boolean`
- `limits.presenceMaxSize` — bytes. Default `512`. Set this when the server limit was changed

```ts
import { createClient } from "@pluv/client";
import type { ioServer } from "./server/pluv-io";
import { treaty } from "./shared/treaty";

const io = createClient<typeof ioServer>().config({
  treaty,
  initialStorage: { messages: [] },
  authEndpoint: ({ room }) => `/api/pluv/authorize?room=${room}`,
  wsEndpoint: ({ room }) => `ws://localhost:3000/api/pluv/room/${room}`,
});
```

`authEndpoint` with `fetch` init:

```ts
authEndpoint: ({ room }) => ({
  url: "/api/room/auth",
  options: {
    method: "post",
    body: JSON.stringify({ room }),
  },
}),
```

## PluvClient

This is the client returned by `createClient`.

### PluvClient.createRoom

Returns a `PluvRoom` instance

Create a `PluvRoom` that websockets can join and leave.

See the [Create Rooms](/docs/guides/rooms/client) docs for more details.

```ts
const room = io.createRoom("my-example-room", {
  // Required when the treaty defines presence
  initialPresence: { selectionId: null },
  // Overrides initialStorage from createClient
  initialStorage: { messages: ["hello world!"] },
});
```

### PluvClient.enter

Returns `Promise<PluvRoom>`

Establishes a websocket connection with a room. If the `PluvClient` specifies an `authEndpoint`, the endpoint will be called when this function is called. Returns the `PluvRoom` that was entered.

> **Note**: This method will fail if the room does not already exist beforehand.

```ts
// frontend/room.ts
const room = io.createRoom("my-example-room", { /* ... */})

// Enter room by room name
io.enter("my-example-room").then(() => {
  console.log("Connected to: my-example-room");
});

// Alternatively, you can pass the PluvRoom instance
io.enter(room).then(() => {
  console.log("Connected to: my-example-room");
});
```

### PluvClient.getRoom

Returns a `PluvRoom` instance or `null` if none is found

```ts
// frontend/room.ts
const room = io.getRoom("my-example-room");
```

### PluvClient.getRooms

Returns `PluvRoom[]`

Retrieves all active rooms under the current `PluvClient` instance.

```ts
// frontend/room.ts
const rooms = io.getRooms();
```

### PluvClient.leave

Returns `void`

Disconnects from a `PluvRoom` and deletes the room on the `PluvClient`. If the room does not exist, nothing happens and the function returns immediately.

```ts
// frontend/room.ts
const room = io.createRoom("my-example-room", { /* ... */})

// Leave room by room name
io.leave("my-example-room");

// Alternatively, you can pass the PluvRoom instance
io.leave(room);
```

## PluvRoom

This is the room returned by `PluvClient.createRoom`.

### PluvRoom.webSocket

Type of `WebSocket | null`

This is the WebSocket that is created and attached to the room when connected to.

### PluvRoom.addEventListener

Returns `() => void`

`addEventListener(kind, handler)` for a WebSocket `open`, `message`, `error`, or `close`. The returned function removes the listener. A room failure (procedure throw, size limit, rejected register) goes to [`subscribe.error`](/docs/api-reference/client#pluvroomsubscribeerror). In React, that failure is [`useRoomError`](/docs/api-reference/react#useroomerror).

```ts
const unsubscribe = room.addEventListener("close", (event) => {
  console.log(event?.code);
});

unsubscribe();
```

### PluvRoom.broadcast

Returns `void`

Sends an event defined on the server router. [`subscribe.event`](/docs/api-reference/client#pluvroomsubscribeevent) receives one. In React, [`useBroadcast`](/docs/api-reference/react#usebroadcast).

```ts
// frontend/room.ts

// The below 2 statements are equivalent
room.broadcast("sendMessage", { message: "hello world!" });

room.broadcast.sendMessage({ message: "hello world!" });
```

### PluvRoom.canRedo

Returns `boolean`

Checks whether calling [PluvRoom.redo](/docs/api-reference/client#pluvroomredo) will mutate storage.

```ts
// frontend/room.ts
const canRedo: boolean = room.canRedo();
```

### PluvRoom.canUndo

Returns `boolean`

Checks whether calling [PluvRoom.undo](/docs/api-reference/client#pluvroomundo) will mutate storage.

```ts
// frontend/room.ts
const canUndo: boolean = room.canUndo();
```

### PluvRoom.connect

Returns `Promise<void>`

Connects to the room if not connected to already. If an `authEndpoint` is configured, this function will call your `authEndpoint`.

```ts
// frontend/room.ts
room.connect().then(() => {
  console.log(`Connected to room: ${room.id}`);
});
```

### PluvRoom.disconnect

Returns `Promise<void>`

Disconnects from the room if already connected.

### PluvRoom.getConnection

Returns `WebSocketConnection`

This returns state information for the current connection to this room.

```ts
const connection = room.getConnection();
```

### PluvRoom.getDoc

Returns `AbstractCrdtDoc` from `@pluv/crdt`

This returns an instance of the `AbstractCrdtDoc` that holds the underlying CRDT doc. For instance, when using `@pluv/crdt-yjs`, this will hold a [yjs](https://yjs.dev/) doc in its `value` property.

```ts
import { yjs } from "@pluv/crdt-yjs";
import { Doc as YDoc } from "yjs";

const doc: yjs.CrdtYjsDoc<any> = room.getDoc();
const ydoc: YDoc = doc.value;
```

### PluvRoom.getMyPresence

Returns `TPresence | null`

Returns the user's current presence data.

```ts
const myPresence = room.getMyPresence();
```

### PluvRoom.getMyself

Returns `UserInfo | null`

Returns a user info object containing the authorized user `data`, presence, `kind`, and `operator` (`null` for users).

```ts
const myself = room.getMyself();
```

### PluvRoom.getOther

Returns `UserInfo | null`

Returns a user info object for one person. The id is `data.id` for both a user and an operator. Omit `kind` to look up a user. Pass `{ kind: "operator" }` to look up an operator. An id-only lookup does not return someone who is only an operator. A list of both is `getOthers`.

```ts
const other = room.getOther(userId);
const operator = room.getOther(userId, { kind: "operator" });
```

### PluvRoom.getOtherByConnectionId

Returns `UserInfo | null`

Resolves a connection id to the person that owns it.

```ts
const other = room.getOtherByConnectionId(connectionId);
```

### PluvRoom.getOthers

Returns `UserInfo[]`

`getOthers({ kinds?: readonly ("user" | "operator")[] })`. Defaults to users. `"operator"` is operators. `"user"` and `"operator"` together is both. In React, [`useOthers`](/docs/api-reference/react#useothers) takes the same `kinds` as its second argument.

```ts
const others = room.getOthers();
const operators = room.getOthers({ kinds: ["operator"] });
```

### PluvRoom.getRoomStats

Returns `RoomStats`

`getRoomStats({ kinds?: readonly ("user" | "operator")[] })`. `connectionCount` and `userCount` for the selected kinds. Defaults to users. In React, [`useRoomStats`](/docs/api-reference/react#useroomstats).

```ts
const { connectionCount, userCount } = room.getRoomStats();
const operators = room.getRoomStats({ kinds: ["operator"] });
```

### PluvRoom.listUsers

`listUsers(options?)` returns `Promise<ListUsersResult>`. Identity page, with no presence. Forward-only. Defaults to users, including yourself. Rows are grouped by `kind` and `data.id`, and each row is `{ data, kind, operator }`. The promise always settles.

`options`:

- `cursor` — `{ kind: "user" | "operator", id: string } | null`
- `kinds` — `readonly ("user" | "operator")[]`. Omit for users
- `limit` — integer from 1 to 100. Default `50`

`FAILED` is a timeout. `NOT_CONNECTED` is returned immediately when the socket is not open. The server method is synchronous: [`sessions.listUsers`](/docs/api-reference/io#listusers).

```ts
const result = await room.listUsers({ cursor: null, limit: 50 });

if (!result.success) {
  // result.error.code: "FAILED" | "INVALID_LIMIT" | "NOT_CONNECTED"
  // result.error.message
  return;
}

// result.users: { data, kind, operator }[]
// result.pageInfo.hasNextPage, result.pageInfo.endCursor
```

### PluvRoom.getStorage

`getStorage(key)` returns the native shared type, such as `Y.Array` with `@pluv/crdt-yjs`. Call this to mutate that type. Returns `null` until storage is loaded, and when `key` is missing. A JSON snapshot is [`getStorageJson`](/docs/api-reference/client#pluvroomgetstoragejson). A listener is [`subscribe.storage`](/docs/api-reference/client#pluvroomsubscribestorage).

```ts
import { Array as YArray } from "yjs";

const messages: YArray<string> | null = room.getStorage("messages");
```

### PluvRoom.getStorageJson

`getStorageJson()` returns the document as JSON. `getStorageJson(key)` returns that top-level field. Call this to read a snapshot. Returns `null` when this connection has no document, and when `key` is missing. The native type is [`getStorage`](/docs/api-reference/client#pluvroomgetstorage).

```ts
const storage = room.getStorageJson();
const messages = room.getStorageJson("messages");
```

### PluvRoom.getStorageLoaded

Returns `boolean`

Call this before [`room.storage`](/docs/api-reference/client#pluvroomstorage). `true` when storage is synced, or when the room is offline and using its local document. [`subscribe.storageLoaded`](/docs/api-reference/client#pluvroomsubscribestorageloaded) fires when this becomes true.

```ts
if (room.getStorageLoaded()) {
  room.storage.addMessage({ text: "hello" });
}
```

### PluvRoom.presence

Call a treaty presence procedure through this proxy. Each call returns a promise and throws when the procedure is missing, or when the local user is not available yet. [`updateMyPresence`](/docs/api-reference/client#pluvroomupdatemypresence) writes fields directly. Do not destructure the proxy. In React, [`usePresence`](/docs/api-reference/react#usepresence).

```ts
await room.presence.select({ id: "item-1" });
```

### PluvRoom.storage

Call a treaty storage procedure through this proxy. Calls return `void` and throw until [`getStorageLoaded`](/docs/api-reference/client#pluvroomgetstorageloaded) is true, without a connection id, or when the procedure is missing. Do not destructure the proxy. In React, [`useStorage`](/docs/api-reference/react#usestorage) is this proxy. [`useStorageField`](/docs/api-reference/react#usestoragefield) reads one field.

```ts
room.storage.addMessage({ text: "hello" });
```

### PluvRoom.redo

Returns `void`

Re-applies the last mutation that was undone via [PluvRoom.undo](/docs/api-reference/client#pluvroomundo).

```ts
// frontend/room.ts
room.redo();
```

### PluvRoom.subscribe.connection

Returns `() => void`

Subscribes to the user's connection state. Returns a function to unsubscribe.

```ts
const unsubscribe = room.subscribe.connection(({
  // The user's authorization state: { token, user }
  authorization,
  // The user's connection state: { id, state }
  connection,
  // The user's websocket
  webSocket,
}) => {
  console.log(authorization, connection, webSocket);
});

// ...

// Unsubscribe to the listener later on.
unsubscribe();
```

### PluvRoom.subscribe.event

Returns `() => void`

Receives an event defined by `PluvIO.procedure`. [`broadcast`](/docs/api-reference/client#pluvroombroadcast) sends one. In React, [`useEvent`](/docs/api-reference/react#useevent).

```ts
// Subscribe to receiveMessage messages

// The below 2 statements are equivalent
const unsubscribe = room.subscribe.event("receiveMessage", ({ data }) => {
  console.log(data);
});

const unsubscribe = room.subscribe.event.receiveMessage(({ data }) => {
  console.log(data);
});

// ...

// Unsubscribe to the listener later on.
unsubscribe();
```

### PluvRoom.subscribe.error

Returns `() => void`

A room failure: a procedure throw, a size limit, or a rejected register. The WebSocket `error` event is [`addEventListener("error")`](/docs/api-reference/client#pluvroomaddeventlistener). In React, [`useRoomError`](/docs/api-reference/react#useroomerror).

```ts
const unsubscribe = room.subscribe.error((error) => {
  console.error(error.message);
});
```

### PluvRoom.subscribe.myPresence

Returns `() => void`

Subscribes to the user's presence state.

```ts
const unsubscribe = room.subscribe.myPresence((myPresence) => {
  console.log(myPresence);
});

// ...

// Unsubscribe to the listener later on.
unsubscribe();
```

### PluvRoom.subscribe.myself

Returns `() => void`

Subscribes to the user's info object. Returns a function to unsubscribe.

```ts
const unsubscribe = room.subscribe.myself((myself) => {
  console.log(myself);
});

// ...

// Unsubscribe to the listener later on.
unsubscribe();
```

### PluvRoom.subscribe.other

Returns `() => void`

Subscribes to one other person, not the currently connected user. Omit `kind` for a user. Pass `{ kind: "operator" }` for an operator. Returns a function to unsubscribe.

```ts
const unsubscribe = room.subscribe.other(userId, (userInfo) => {
  const { data, presence } = userInfo;

  console.log(data, presence);
});

// ...

// Unsubscribe to the listener later on.
unsubscribe();
```

### PluvRoom.subscribe.others

Returns `() => void`

Other people in the room. The second argument is `{ kinds?: readonly ("user" | "operator")[] }`, the same bag as [`getOthers`](/docs/api-reference/client#pluvroomgetothers).

```ts
const unsubscribe = room.subscribe.others((others) => {
  console.log(others);
});

// ...

// Unsubscribe to the listener later on.
unsubscribe();
```

### PluvRoom.subscribe.roomStats

Returns `() => void`

`connectionCount` and `userCount`. Pass `{ kinds }` the same way as [`getRoomStats`](/docs/api-reference/client#pluvroomgetroomstats).

```ts
const unsubscribe = room.subscribe.roomStats((stats) => {
  console.log(stats.connectionCount, stats.userCount);
});
```

### PluvRoom.subscribe.storage

Returns `() => void`

Runs the callback when a field, or the whole document, changes. The callback receives JSON. [`getStorage`](/docs/api-reference/client#pluvroomgetstorage) reads the native type once.

```ts
room.subscribe.storage("messages", (messages: string[]) => {});

const unsubscribe = room.subscribe.storage.messages((messages: string[]) => {
  console.log(messages);
  const sharedType = room.getStorage("messages");
});

// ...

// Unsubscribe to the listener later on.
unsubscribe();
```

Pass only the callback to receive the whole document.

```ts
// Access a top-level property (serialized)
room.subscribe.storage.messages((messages: string[]) => {});

// Access to the entire storage object (serialized)
room.subscribe.storage((storage) => {
//                      ^? const storage: { messages: string[] };
});
```

### PluvRoom.subscribe.storageLoaded

Returns `() => void`

Runs the callback when storage finishes loading. [`getStorageLoaded`](/docs/api-reference/client#pluvroomgetstorageloaded) reads that flag once.

```ts
room.subscribe.storageLoaded(() => {
  console.log("storage was loaded");
});
```

### PluvRoom.transact

Returns `void`

Performs a mutation that can be tracked as an operation to be undone/redone (undo/redo).
When called without an origin, the origin will default to the user's connection id.

You can specify a 2nd parameter to transact with a different transaction origin.

```ts
const messages = room.getStorage("messages");

room.transact((tx) => {
  messages?.push(["hello world!"]);

  // `tx` is the storage root for this transaction
  tx.messages.push(["hello world!"]);
});

// This will also be undoable if `"user-123"` is a tracked origin.
room.transact(() => {
  room.get("messages").push(["hello world!"]);
}, "user-123");
```

### PluvRoom.undo

Returns `void`

Undoes the last mutation that was applied via [PluvRoom.transact](/docs/api-reference/client#pluvroomtransact).

```ts
// frontend/room.ts
room.undo();
```

### PluvRoom.updateMyPresence

Returns `Promise<void>`

`updateMyPresence(patch)` writes presence fields directly and broadcasts them. `patch` is a partial presence object, or `(current) => partial`. A treaty presence procedure is [`room.presence`](/docs/api-reference/client#pluvroompresence). In React, the setter from [`useMyPresence`](/docs/api-reference/react#usemypresence) is this method.

```ts
await room.updateMyPresence({ selectionId: "id_..." });

await room.updateMyPresence((current) => ({
  selectionId: current?.selectionId ?? null,
}));
```
