## `@pluv/treaty`

> Isomorphic schema and procedure contract for [@pluv/io](https://www.npmjs.com/package/@pluv/io) and [@pluv/client](https://www.npmjs.com/package/@pluv/client)

**👉 See full documentation on [docs.pluv.io](https://docs.pluv.io/docs). 👈**

## Installation

```bash
# npm
npm install @pluv/treaty

# yarn
yarn add @pluv/treaty

# pnpm
pnpm add @pluv/treaty
```
